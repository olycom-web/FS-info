### N8510-24CD8D, 24-Port Ethernet Data Center Switch, 24 x 200Gb QSFP56, with 8 x 400Gb QSFP-DD Uplinks, PicOS®, Broadcom Trident 4 Chip

The N8510-24CD8D is a 1RU system featuring 24x 200G QSFP56 and 8x 400G QSFP-DD ports, delivering wire-speed throughput of up to 8.0 Tbps. Each 200G port supports flexible configurations of either 2x 100/50GbE or 4x 50/25GbE via breakout, while each 400G port supports 400GbE, 200GbE, 100GbE, or 50GbE. This system is optimized for Top of Rack connectivity for next generation 50/100/200G PAM4 based server NICs and Spine use cases.

With these flexible port configurations, the switch enables customers to design networks that support diverse applications and east-west traffic patterns in modern data centers, while ensuring backward compatibility with existing compute infrastructure.
