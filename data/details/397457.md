### S3220-8M, 8-Port Ethernet L2 Web-Managed Switch, 8 x 2.5GBASE-T/Multi-Gigabit Ports, with 1 x 10Gb SFP+ Uplink, Fanless

The S3220-8M is a compact Layer 2 web-managed switch designed for high-speed, multi-device network access in small- to medium-sized deployments, including small-business open-plan offices, student dormitories, and mid-sized conference rooms. With 8x 2.5GBASE-T/Multi-Gigabit ports, it provides high-speed connectivity for multiple bandwidth-intensive devices, while the 10G SFP+ uplink offers high-capacity upstream connectivity. Its fanless design enables silent operation, and desktop and wall-mount options provide flexible deployment in space-constrained environments.

Powered by a Realtek chip, the switch features an intuitive Web UI for simplified network configuration and management. Features including IEEE 802.3x Flow Control, VLAN, LACP, IGMP Snooping, QoS, and DHCP help optimize traffic management and improve network efficiency, stability, and reliability.
