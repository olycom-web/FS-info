##### Project demands

The primary aim was to revamp the core network to:

- Assist customers to sort out old network layouts
- Improve Network Performance and Reliability
- Elevate Network Security Levels
- Facilitate High-Quality Video Streaming
- Support Efficient Remote Editing and Real-Time Transmission

##### Solution

**Core layer: BDCOM S8506E Core Switch**

Function: Serves as the central hub for data forwarding and aggregates all convergence access networks.

Benefit: Provides a robust and reliable core with high data throughput, ensuring seamless data transmission across the network.

**Aggregation Switching**

Models: BDCOM S2928E and S2928F Switches

Function: Replaces the existing, lower-rate switches to aggregate data from access switches before it is forwarded to the core switch.

Benefit: Ensures high-speed, ten-gigabit uplinks, improving the overall speed and efficiency of the network.

**Access Switching**

Model: BDCOM S2500 Series Gigabit Managed Switches

Function: Connects end-user devices to the network, offering high-speed access to applications and services.

Benefit: Allows for high-speed internet access, enhancing the efficiency of daily office operations.

##### Result

This solution aims to revamp the network infrastructure, focusing on optimizing data transmission speed and improving overall network efficiency and reliability. By implementing high-speed switches at the core, aggregation, and access layers of the network, the solution ensures fast, seamless connectivity, enabling a more efficient and productive office environment.

Customer is extremely satisfied with the results of this network renovation project, and office efficiency has seen a substantial improvement.
