**Background**

As part of a Data Center upgrade project, PT Wirelessindo Solusi Teknologi sought a Layer 3 switch solution that could deliver high performance, advanced routing capabilities, and scalability — all at a cost-effective price point. Their primary objective was to enhance network speed, reliability, and manageability while maintaining compatibility with existing infrastructure.

**Challenges**

- High-Speed & Reliable Connectivity: Delivering stable, high-performance internet and data transmission for critical operations.
- Seamless Integration: Ensuring compatibility and smooth interoperability with the existing network infrastructure.
- Scalability & Manageability: Building a network architecture that is secure, scalable, and easy to manage for future growth.

**Solution**

To meet these requirements, PT Wirelessindo Solusi Teknologi deployed an Enterprise-grade L3 Managed Switch solution which key features are -

- Virtualization & High Availability: Supports BVSS (BDCOM Virtual Switch System) — enabling multiple physical devices to operate as a single logical switch for simplified management and redundancy.
- High-Capacity Hardware: Equipped with 2×100G/40G QSFP28 and 24×10G/GE SFP+ ports, offering massive throughput for data center applications.
- Superior Performance: Backplane capacity of 880Gbps and forwarding rate of 660Mpps, ensuring non-blocking data transmission.
- Redundant Power Supply: Supports 1+1 power backup for uninterrupted service availability.
- Advanced Routing Protocols: Comprehensive Layer 3 feature set including RIP, OSPF, BGP, ECMP, ISIS, and PBR.
- Enhanced Reliability: Supports VRRP, EAPS, ERPS, and Static/LACP Link Aggregation for fault-tolerant network design.

**Results**

- Ultra-Fast Internet: High-speed connectivity to each unit, enabling smooth content delivery.
- Scalable and Future-Proof: Easy to expand as the number of users or bandwidth requirements increase.
- Reliable and Secure: Advanced network management features ensure secure, stable, and efficient operations.
