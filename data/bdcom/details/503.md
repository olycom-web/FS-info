## Features

### ACL
- VLAN ACL
- L2~4 ACL
- IPv4, IPv6 ACL

### IPv6
- ICMPv6, DHCPv6, ACLv6, IPv6 Telnet
- IPv6 Neighbor Discovery
- Path MTU Discovery
- MLD Snooping

### Management and maintenance
- Console, Telnet, SSH 2.0
- Zero Touch Provisioning (ZTP)
- HTTP/HTTPS
- SNMP v1/v2/v3
- Upload and download files through TFTP/FTP
- Remote Network Monitoring (RMON)
- Syslog
- SPAN, RSPAN

### Reliability
- Static/LACP LAG
- Ethernet OAM
- ISSU
- Backuplink
- VRRP

### Security
- Identification and filtering of L2/L3/L4-based ACL
- Suppression of broadcast, multicast and unknown unicast packet
- Port isolation
- Port security, IP+MAC+port binding
- DHCP sooping, DHCP option82【原文如此】
- IEEE 802.1x authentication
- Radius and TACACS+ authentication
- Command line hierarchical protection

### QoS
- CAR traffic control
- 802.1P/DSCP priority remark
- Multiple queuing algorithms such as SP, WRR or SP+WRR
- IP ACL/ANY/VLAN/COS/DSCP/IP Preference based QoS
- Traffic supervision and traffic shaping
- Drop, Redirect

### DHCP
- DHCP Server/Client/Relay
- DHCP Snooping

### IP routing
- Static route
- RIP, OSPF
- 128 routing table

### Multicast
- MVR
- IGMP Snooping
- IGMP Fast Leave
- Multicast group policy and multicast number limit

### Ring protection
- 802.1D (STP), 802.1W (RSTP), 802.1S (MSTP)
- BPDU protection, root protection and ring protection
- EAPS
- G.8032 ERPS

### VLAN
- 4K VLAN entries
- GVRP
- QinQ
- Private VLAN
- Voice VLAN
