## Features

### Heat dissipation
- During long-term use (24 hours), the device's heat generation will not cause performance degradation or deformation/damage of components

### Configuration Management
- Multiple management methods including Web, TELNET, TR069, OMCI, OAM, etc.
- Software upgrades via TFTP/WEB/TR069/OLT

### Network Security
- Port protection
- Firewall MAC/IP/Port/URL/Domain filtering
- DDoS
- Port storm suppression
- Port mapping

### Reliability
- Supports Loop-detect
- Supports Dying-Gasp
- Supports Type B dual-homing protection

### QoS
- Backpressure flow control (half-duplex)
- IEEE 802.3x flow control (full-duplex)
- Head of Line blocking prevention mechanism
- IEEE 802.1p, CoS
- 8 priority queues per port
- WR, SP, and FIFO queue scheduling algorithms
- Port rate limiting

### Multicast
- Supports IGMP-Snooping
- Supports CTC-defined dynamic multicast function
- Supports MLD-Snooping

### Standards
- ITU-T G.987.3, G.988, G.989
- People's Republic of China Communication Industry Standard GB/T 43699-2024 "Access Network Technical Requirements for 10Gbit/s Symmetrical Passive Optical Network (XGS-PON)"
- IEEE 802.1Q, VLAN

### PON interface
- Downlink 10Gbps / Uplink 10Gbps transmission rate
- Network coverage radius: 20 kilometers
- Receiver sensitivity: no more than -28dBm
- Transmit optical power: 0.5~5dBm
