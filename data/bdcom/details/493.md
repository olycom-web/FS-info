## Overview

BDCOM GP6606 Series complies with ITU-T G.984/G.988 and meets requirements about GPON OLT in Network Access Technical Requirements. It fully supports CTC2.0, automatic discovery and cooperation with ONUs of different manufacturers.

## Features

### Network Availability
- STP/RSTP/MSTP
- BPDU guard
- EAPS

### Management
- Various management modes such as CLI, Telnet, SSH, HTTP, SSL and SNMP
- ISSU
- FTP/TFTP
- Debug output
- NTP
- SPAN

### Network Security
- L2~4 ACL
- Flow-based ACL
- MAC limitation
- MAC sticky
- Port isolation
- Packet storm control
- Transmission data encryption on the PON interface
- Anti attack for DDOS, TCPSYN-flood, UDP-flood, ARP-flood, etc.

### DHCP Function
- Server/Relay/Client
- DHCP snooping
- DHCP option 66, 67, 82
- DAI
- IP source guard

### Reliability
- Unidirectional Link Detection (UDLD)
- Hot swap of the PON optical module
- Optical path protection of GPON (type B/C)
- Abnormal luminescence ONU detection such as long luminescence
- IEEE 802.3ad LACP

### QoS
- Backpressure flow control (half duplex)
- IEEE 802.3x flow control (full duplex)
- IEEE 802.1p, CoS
- WRR, SP and FIFO queue schedule
- Limiting the uplink/downlink rate based on each ONU
- DBA and SLA

### Layer 3 Function
- Static route · RIPv1/v2 · OSPF · BGP

### Multicast
- L2 multicast · IGMP snooping · MLD snooping · Fast-leave

### VLAN
- Port/IP/Protocol/MAC-based VLAN
- 4K VLAN
- QinQ and flexible QinQ

### Standards
- ITU-T G.984/G.988
- IEEE 802.11D, Spanning Tree
- IEEE 802.1Q, VLAN
- IEEE 802.1w, RSTP
- IEEE 802.3ad physical link static/dynamic aggregation (LACP), Ethernet-II
