## Features

### Wireless
- 802.11b/g/n/ac
- 2x2 MIMO
- Multi SSID
- SSID encryption
- Wireless channel (configurable)

### Reliability
- Loop detection
- Dying-Gasp
- TX/RX optical power alarm

### Multicast
- IGMP-Snooping
- CTC defined dynamic multicast function
- MLD-Snooping
- Multicast group limitation
- Multicast fast-leave

### Network Security
- MAC address number limit
- MAC filter
- Port protect

### Voice Service
- SIP, T.38 FAX
- Three-way calling
- Call waiting
- Hot-line calling

### Management
- Management modes including CLI, HTTP, SNMP, TR069 and TELNET
- Software upgrade through TFTP and WEB, OMCI, etc.
- Local or server syslog

### QoS
- Backpressure flow control (half-duplex)
- IEEE 802.3x flow control (full duplex)
- Against Head of Line mechanism
- IEEE 802.1p, CoS
- Four priority queues on each port
- WR, SP and FIFO queue schedule algorithms
- Port rate limit
- SLA and DBA

### xPON Service
- AES128 algorithm encryption
- MAC/Loid/Hybrid authentication

### IP Service
- DHCP server/client
- Routing/Bridging/Hybrid mode
- DNS, DDNS
- PPPOE
- NAT/NAPT

### VLAN
- 4K VLAN
- Port based VLAN
- IEEE 802.1Q VLAN
- Tag/Transparent/Aggregation/Trunk/Translation mode VLAN
- CTC2.0 defined VLAN

### Standards
- ITU-T G.984/G.988
- IEEE 802.3ah
- GBT33845-2017, YD/T 1475-2006
- IEEE 802.1Q, VLAN
- ITU-T Y.1291
