## Features

### Management and maintenance
- Console, Telnet, SSH, SNMP
- ping, traceroute
- Syslog
- LCD color screen to provide real-time operation, fault diagnosis and online help
- Cloud management through Pallas

### IPv6 protocol
- IPv4/v6 dual stack
- Ipv6 static routing
- IPSec v6
- Ipv6 Dynamic routing such as RIPng, OSPFv3, BGP4+

### Network security
- AAA, PPP, CHAP and MS-CHAP authentication
- IP and MAC-based ACL firewall policy; Rich VPN protocols such as IKE, IPSec, L2TP/PPTP, GRE
- Nested deployment of multiple VPN protocols
- Anti-Flood capability for ARP, IP, ICMP, TCP
- Attack protection such as Ping of Death, Tear-drop, WinNuke, Smurf, etc.

### Multicast protocol
- IGMP, PIM-SM, PIM-DM

### IP-based service
- IP, ICMP, TCP, UDP
- DNS and DDNS
- NTP
- FTP and TFTP
- PPPoE server

### DHCP
- DHCP server, DHCP Relay
- DHCP Option43, 60, 82

### NAT
- NAT based on IP, port and address pool
- SNAT, DNAT
- NAT port mapping
- NAT concurrent connection limit
- NAT Application Layer Gateway (ALG)

### Routing protocol
- Static routing, PBR
- RIP v1/v2, OSPF v2, BGP
- Floating routing and routing automatic backup
- Keepalive, BFD remote link detection

### QoS
- Traffic classification based on IP 5-tuple
- Committed Access Rate (CAR) and Generic Traffic Shaping (GTS)
- PQ, CQ, CBWFQ

### WAN access
- Static IP address, DHCP dynamic IP and PPPoE dial-up access
- Multi-line networking
- Load balancing of multiple policies (equivalent, weighted)

### LTE wireless
- TDD and FDD-LTE full Netcom modules, backward compatible
- APN dial-up
- Dual-SIM single-standby and wireless backup networking (applicable to some models)

### Link layer protocol
- Point to Point Protocol (PPP)

### Ethernet protocol
- 802.3 protocol family, 802.1Q VLAN, Rate-limit, broadcast storm suppression

### ARP
- ARP dynamic learning, ARP static binding, free ARP anti-spoofing
