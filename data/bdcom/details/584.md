## Features

### Thermal Performance
- Fanless, with aluminum housing for passive cooling

### Installation
- DIN-rail mounting

### Management
- Web, Telnet, TR069, OMCI, OAM
- Software upgrade through TFTP/WEB/TR069/OLT

### VLAN
- 4K VLAN
- Port based VLAN
- IEEE 802.1Q VLAN
- VLAN Aggregation
- VLAN Translation
- VLAN Stacking

### Security
- Port-based MAC address limitation
- Port protection
- Port storm control

### Reliability
- Loop detect
- Dying-Gasp
- Type B single/dual homing protection

### QoS
- Back pressure flow control (half duplex)
- IEEE 802.3x flow control (full duplex)
- Head of Line (HoL) mechanism
- IEEE 802.1p, CoS
- 4 priority queues per port
- WR, SP and FIFO
- Port rate limit

### Multicast
- IGMP-Snooping
- CTC defined dynamic multicast
- MLD-Snooping

### Standards
- ITU-T G.984/G.988, IEEE802.3ah
- GBT33845-2017, YD/T 1475-2006
- IEEE 802.1Q, VLAN

### PON port
- EPON/GPON self-adaptation
- GPON: downlink 2.5Gbps/uplink 1.25Gbps
- EPON: downlink 1.25Gbps/uplink 1.25Gbps
- Network covering radius: 20km
- Hi-sensible optical receiver: ≥-28dBm
- Radiation power: 0.5~5dBm
- Type of the optical port: SC/UPC
