## Features

### Energy saving
- IEEE 802.3az

### Management
- Console, Telnet, SSH 2.0
- Zero Touch Provisioning (ZTP)
- Web-GUI
- SNMP v1/v2c/v3
- Upload and download of FTP/TFTP/SFTP files
- RMON event history
- Traffic statistical analysis such as sFLOW

### Reliability
- Power 1+1 backup
- Static/LACP link aggregation
- EAPS, ERPS
- HSRP, VRRP
- GR for OSPF and BGP
- BFD for OSPF and BGP
- ISSU

### Security features
- L2~L4 ACL flow identification and filtering security mechanism
- DDoS attack prevention, TCP-SYN/UDP Flood attack prevention
- Suppression of multicast, broadcast, and unknown unicast packets
- Port isolation
- Port Security, IP+MAC+port binding
- DHCP Snooping, DHCP Option 82
- IEEE 802.1x authentication
- Radius, TACACS+, URPF
- Command line hierarchical protection

### QoS
- Traffic classification based on fields in L2/L3/L4 protocol headers
- Committed Access Rate (CAR) traffic restriction
- Re-marking of 802.1P/DSCP priority
- Multiple queuing algorithms such as SP, WRR or SP+WRR
- Congestion avoidance mechanisms like Tail-Drop and WRED
- Traffic supervision and traffic shaping
- Ingress and Egress ACL, supports matching L2, L3, L4 and IP quintuples, and performs replication, forwarding and discarding
- Hash-based load balancing algorithm to ensure session integrity

### IPv6
- ICMPv6, DHCPv6, ACLv6 and IPv6 Telnet
- IPv6 neighbor discovery
- Path MTU discovery
- MLD v1/v2
- MLD snooping
- IPv6 Static Routing, RIPng, OSPFv3, BGP4+
- Manual tunnel, ISATAP tunnel, 6-to-4 tunnel

### IPv4
- Static routing, RIP v1/v2, OSPF, BGP, IS-IS, BEIGRP【原文如此】
- Policy Based Routing (PBR)
- ECMP
- BFD for OSPF, BGP

### Multicast
- IGMP v1/v2c/v3
- IGMP Snooping
- IGMP Fast Leave
- Multicast group policy and multicast number limit
- MVR
- PIM-SM, PIM-DM

### STP
- 802.1d STP, 802.1w RSTP, 802.1s MSTP
- BPDU protection, root protection and ring protection

### Vxlan
- Manually configuring VxLAN tunnel
- VxLAN distributed gateway
- VxLAN dual-active link access
- VxLAN interconnection across data centers
- VxLAN pass-through of L2 Protocol packets
- Supports modification of VxLAN outer header DSCP
- BGP EVPN
- Supports overlay split horizon, and separate control on different VNIs

### Environment
- Operating temperature/humidity: -10°C-50°C; 10%-90% non-condensing
- Storage temperature/humidity: -20°C-70°C; 5%-95% non-condensing
