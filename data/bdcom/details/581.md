## Overview

BDCOM GP1702 Series is a new generation smart ONT for integrated multi-service broadband access networks. GP1702 Series, involving multiple models, supports common enterprise broadband access service, POE service and outdoor wide-temperature. BDCOM GP1702 series is compatible with EPON and GPON networks: complied with the international standard ITU-T G.984/G.988 and IEEE802.3ah, PRC Communication Industry Standard GB/T33845-2017 and YD/T 1475-2006, and China Telecom EPON/GPON Technical Requirement CTC 3.0 standard. Standing out with great interoperability and operability, BDCOM GP1702 series can auto discovery and register with OLTs of mainstream manufacturers in the industry.

## Features

### Reliability
- Loop detection
- Dying-Gasp
- Wavelength(nm): Upstream (1310)±20; Downstream (1490)±15
- TX/RX optical power alarm

### Multicast
- IGMP-Snooping
- CTC defined dynamic multicast function
- MLD-Snooping
- Multicast group limitation
- IGMP V2/V3
- Multicast fast-leave

### Network Security
- MAC address number limit
- MAC filter, MAC learned setup
- Port protect

### Management
- Management modes including CLI, HTTP, SNMP and TELNET
- Software upgrade through TFTP and WEB, XML, OMCI, OAM, etc.
- Local or server syslog
- Authentication exemption

### QoS
- Backpressure flow control (half-duplex)
- IEEE 802.3x flow control (full duplex)
- Against Head of Line mechanism
- IEEE 802.1p CoS
- Four priority queues on each port
- 802.1D and 802.1ad bridging
- Port speed limit
- SLA and DBA

### EPON Service
- AES128 algorithm encryption
- MAC/Loid/Hybrid authentication

### VLAN
- 4K VLAN
- Port based VLAN, bridging mode
- IEEE 802.1Q VLAN; Tag/Transparent/Aggregation/Trunk/Translation mode VLAN
- CRC2.0 define VLAN
- VLAN transparent transmission
- VLAN filtering

### Standards
- ITU-T G.984.x/G.988.x
- IEEE 802.3ah
- GBT33845-2017, YD/T475-2006
- IEEE 802.1Q, VLAN
- IEEE 802.1w, RSTP
- ITU-T Y.1291
- Auto-MDI/MDIX
- IEEE 802.3af/at
